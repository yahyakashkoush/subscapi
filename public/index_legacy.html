كيفية استخدام مفتاحك في أدواتك المفضلة

الروابط تعمل تماماً مثل روابط OpenAI الرسمية مع أقصى درجات السرعة والتوافق التام.

إعداد المفتاح في محرر Cursor:

  1. افتح إعدادات Cursor بالضغط على Ctrl + , أو Cmd + , ثم توجه لقسم Models.
  2. قم بإيقاف المفتاح الافتراضي، ثم فعّل خيار OpenAI API Key أو Override OpenAI Base URL.
  3. ضع البيانات التالية في الحقول:
Cursor Settings Configuration 
Base URL: http://localhost:3000/v1
API Key:  sk-subsc-your-key-here
Model:    gpt-6.1-sol (أو gpt-4o)

إعداد المفتاح في إضافة Cline / Roo Code:

  1. افتح إعدادات Cline من الشريط الجانبي.
  2. اختر API Provider: OpenAI Compatible.
  3. أدخل الرابط الأساسي والمفتاح واسم النموذج:
Cline Provider Config 
Base URL: http://localhost:3000/v1
API Key:  sk-subsc-your-key-here
Model ID: gpt-6.1-sol

استخدام المفتاح في لغة Python مع مكتبة OpenAI:

main.py 
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3000/v1",
    api_key="sk-subsc-your-key-here"
)

response = client.chat.completions.create(
    model="gpt-6.1-sol",
    messages=[{"role": "user", "content": "مرحبا! هل أنت متصل؟"}]
)

print(response.choices[0].message.content)

تجربة الطلب عبر cURL من التيرمينال:

Terminal 
curl http://localhost:3000/v1/models \
  -H "Authorization: Bearer sk-subsc-your-key-here"
