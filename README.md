# 🚀 مراقب استهلاك ورصيد الـ API (AI Quota & Usage Monitor)

موقع ولوحة تحكم متكاملة لفحص ومراقبة استهلاك ورصيد مفاتيح الذكاء الاصطناعي (OpenAI, OneAPI, NewAPI, OpenRouter وغيرها) ومعرفة المتبقي بالدولار والتوكنات المتبقية والحدود والصلاحية.

---

## 🌟 المميزات

1. **عرض الرصيد المتبقي بالدولار ($)**:
   - الرصيد المتبقي بدقة (مثل `$99.9996 USD`).
   - إجمالي الحصة الممنوحة (Total Limit).
   - المبلغ المستهلك حتى اللحظة مع نسبة الاستهلاك (%).
2. **الصلاحية والانتهاء**:
   - عدد الأيام المتبقية وتاريخ الانتهاء المحدد.
3. **تفاصيل التوكنات والاستهلاك اليومي**:
   - تكلفة اليوم، عدد الطلبات (Requests).
   - توكنات الإدخال (Input Tokens)، توكنات الإخراج (Output Tokens)، وتوكنات قراءة الكاش (Cached Tokens).
   - إجمالي الاستهلاك التراكمي منذ إنشاء المفتاح.
4. **معدلات السرعة والحدود**:
   - RPM (طلبات بالدقيقة).
   - TPM (توكنات بالدقيقة).
   - متوسط زمن المعالجة والاستجابة.
5. **النماذج المتاحة (Available Models)**:
   - قائمة بجميع النماذج المصرح بها للمفتاح (مثل `gpt-6.1-sol`).
   - إمكانية البحث والنسخ بضغطة زر.
6. **سجل الاستهلاك اليومي والرسم البياني**:
   - رسم بياني تفاعلي (Chart.js) وجدول زمني للاستهلاك عبر الأيام.
7. **محفظة المفاتيح (Saved Keys Wallet)**:
   - إمكانية حفظ أكثر من مفتاح بأسماء مخصصة محلياً بالمتصفح (localStorage) والتبديل بينهم بضغطة زر.
8. **المراقبة والتحديث التلقائي**:
   - تحديث دوري اختياري (كل 15 ثانية، 30 ثانية، دقيقة، 5 دقائق).
9. **دعم كامل للغتين والمظهرين**:
   - واجهة عربية أصيلة (RTL) مع إمكانية التبديل للإنجليزية (LTR).
   - الوضع الليلي (Dark Mode) الأنيق والوضع النهاري (Light Mode).
10. **تصدير ومشاركة**:
    - نسخ ملخص سريع للحافظة أو تصدير التقرير كملف JSON.

---

## ⚙️ طريقة التشغيل

الموقع يعمل حالياً على جهازك على الرابط:
👉 **`http://localhost:3000`**

لتشغيله في أي وقت مستقبلاً:
```bash
npm start
```
أو عبر:
```bash
node server.js
```
